# AI Capstone

This repository contains my capstone project for the FlyRank AI Front-End Engineering Internship.

## What This Project Does

This project demonstrates AI-assisted development workflows while building a production-ready front-end application.

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js

## Goals

- Learn AI-assisted development.
- Build a production-ready application.
- Practice AI-assisted coding workflows.

## Getting Started

1. Clone the repository

```bash
git clone <your-repo-url>
cd ai-capstone
```

2. Install dependencies

```bash
npm install
```

3. Run the project

```bash
npm start
```
